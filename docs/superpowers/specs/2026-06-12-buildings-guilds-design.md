# Buildings & Guilds section — design

Date: 2026-06-12. Approved by templeglancer in conversation.

## Goal

Add a Buildings & Guilds page to the AGO compendium. Units remain the core of
the site; the new page documents every building chain and guild, cross-linked
with the unit page in both directions.

## Decisions (made with the user)

- **Depth: catalog + key effects.** Picture, description, chain tiers,
  construction cost/time, recruited units, and a curated effect list
  (walls, law, growth, trade, upgrades…). Not a full EDB dump.
- **Placement: separate page** (`buildings.html`), generated by the same
  `node build.js` run. Nav links in both page headers.
- **Approved follow-ups** (later phases): faction overview page; guild-point
  triggers parsed from `eopData` Lua; settlement tech-tree view.

## Data sources

| File | Use | Parser |
| --- | --- | --- |
| `data/export_descr_buildings.txt` | 161 chains, 562 levels: tiers, city/castle, cost, build time, effects, recruit pools, faction/region/event requirements | extend existing `parseEdb` |
| `data/text/export_buildings.txt` | display names + descriptions (culture/faction-suffixed tags) | existing `parseExportUnits` + `buildingDisplayName` |
| `data/export_descr_guilds.txt` | 13 guilds: chain + per-level point thresholds | new tiny parser |
| `data/ui/<culture>/buildings/#<culture>_<level>.tga` | building pictures | existing TGA→PNG pipeline → lazy `buildingpics/` |

## Page structure

- Same parchment styling; shared CSS between the two pages.
- Controls: search box + category buttons.
- One row per chain, grouped under category headers in fixed order:
  **Military, Defence, Economy, Landmarks, Guilds, Other** (guilds land at the
  bottom). Category is derived: `guild` in chain name → Guilds; every level
  region-locked → Landmarks; wall levels → Defence; trains units → Military;
  trade/farm/mine/road/income → Economy; else Other.
- Expanded row = tier ladder: per level its picture, name, city/castle kind,
  construction cost + turns, curated effects line, and recruited units linking
  to `index.html#unit-slug`. Guild levels additionally show their guild-point
  threshold.
- Deep links (`buildings.html#chain-slug`) with the same hash/scroll mechanics
  as the unit page. Unit page "Buildings" rows become links to the chain entry.

## Curated effects (whitelist)

walls/towers/gates, law, happiness, growth, health, loyalty, trade, tax,
income, mining, farming, roads, free upkeep, recruit morale/experience,
recruitment slots, retrain cost, armour & weapon upgrade tiers, religion
(faction influence), build cost/time bonuses, trade fleets, naval cost,
games/races, archer/cavalry experience, fire risk. AI-only (`is_the_ai`)
lines are skipped; other conditional lines are shown with a dim
"(conditional)" marker and the raw condition in a tooltip.

## Out of scope for this phase

Guild-point earning rules (guildData.lua — phase 2), faction overview page
(phase 3), tech-tree walker (phase 4).
