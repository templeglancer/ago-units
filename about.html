This site

The AGO Compendium is an independent data-reference platform for the AGO mod. It is generated directly from the mod's own data files — every stat, threshold, trigger and scroll on these pages is read from the same files the game reads, and the whole site is rebuilt with one command after each mod update. The single exception is the combat primer on the Mechanics page, which reflects community-established engine knowledge. The site is not affiliated with the mod's development team; their work is credited below.
